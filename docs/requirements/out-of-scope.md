# 首期明确不做

这些内容有后续触发条件。未触发前不要在首期计划里膨胀。

| 不做 | 触发条件 |
| --- | --- |
| 微服务 / 多 API 副本 | 需要水平扩展写流量 |
| 独立 Git 仓库拆分前后端 | 多团队独立发布且契约已稳定 |
| Next.js 直连数据库 | 永不作为正式方案 |
| Hono RPC 作为对外契约 | 除非只做内部实验且不面向多端 |
| Edge Runtime | 放弃本地 SQLite / 文件之前 |
| PostgreSQL | 多实例、多家庭 SaaS 或必须跨机共享 |
| Worker 进程 | 定时任务、大文件、长 AI、导出等出现 |
| 微信小程序 / App / 桌面端 | 第二客户端真正开工时 |
| Bearer 产品化（刷新、设备撤销） | 原生客户端需要登录时 |
| 多家庭 SaaS、注册、计费 | 服务超过一个家庭 |
| 完整营养数据库、库存消耗 | 配餐需要营养约束时 |
| 图片识别、菜谱导入爬虫 | 有明确输入源时 |
| 复杂日历 / 通知推送 | 任务提醒成为刚需时 |
| `packages/domain` 前后端共享 | 永不作为默认；仅当存在无服务端能力的纯常量 |
| Orval / 完整设计系统 | Web 对生成 hooks / 组件库有明确痛点时 |
