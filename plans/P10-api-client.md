# P10 OpenAPI 客户端生成

- 状态：已完成
- 分类：契约
- 依赖：P03（实际随模块路由补全后重生）

## 目标

`packages/api-client` 从 `openapi/openapi.json` 生成类型，提供 browser / server client。Web 只依赖该包。

## 验收

- [x] `schema.d.ts` 标注自动生成
- [x] browser client 默认 `baseUrl: /api/v1`
- [x] server client 使用 `INTERNAL_API_BASE_URL` 并转发 cookie
- [x] 不从 `@family-os/api` 导入类型

## 证据

- `packages/api-client/src/schema.d.ts` 头部：auto-generated by openapi-typescript
- `packages/api-client/src/client.ts` 提供 browser / server 两个工厂
- `apps/web/package.json` 只依赖 `@family-os/api-client`，不依赖 `@family-os/api`
