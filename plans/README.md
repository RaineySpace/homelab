# 计划主表

本目录是 Family OS 的**唯一计划账本**。所有实现计划都在这里登记。状态只允许以下四类：

| 状态 | 含义 |
| --- | --- |
| 已完成 | 验收标准已在当前工作区被证据证明 |
| 正在执行 | 当前正在改这一项 |
| 未完成 | 尚未开始或未达到验收 |
| 已阻塞 | 缺少依赖、密钥或外部条件，无法继续 |

更新规则：

1. 先改本表，再改对应计划文件里的状态，两者必须一致。
2. 新计划必须新增一行，禁止只在聊天里口头增加范围。
3. 完成一项时，把验收证据写进该计划文件的「证据」一节（命令、测试名、关键路径）。
